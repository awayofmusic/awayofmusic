## A Way of Music
Created by Tristano Tenaglia. <br>

To Run (double-click or from terminal) : <br>
windows : windows_thegame.exe <br>
macos : macos_thegame <br>
linux : linux_thegame <br>
once open press ctrl+alt+t <br>
type in : load_op intro guides/intro <br>
press enter <br>
<br><br>

To Build (from base directory) : <br>
git clone https://github.com/asmvik/miniaudio-jai commit 8e8e78e4b481d9f237c667f655326f8f873afe08 <br>
git clone https://github.com/arjenwitteveen/jai-midi commit f206ab8a74449c860878579d76acf15d6a35676a <br>
git clone https://github.com/rluba/jaison commit 9a407e903d64437ee34d0b0ee6fe7a06095a44d6 <br>
jai build_thegame.jai -import_dir "." <br>
